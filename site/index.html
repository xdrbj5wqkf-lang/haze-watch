How to read this

The verdict comes from the CAMS forecast, a global model at about 45 km, converted to an approximate Malaysian API. Official API uses a running average and reacts more slowly than these hourly values.

Smoke tracking is our own model. Each fire cluster releases smoke that drifts with the forecast wind at 850 hPa, thins over 36 hours and washes out in rain. It is not yet calibrated; read it for direction and timing.

Confidence is high when the two agree and low when they disagree. Cloud can hide fires from the satellites, so a quiet map can understate smoke.

Updated every hour. For official readings use APIMS.

Fire data: NASA FIRMS. Forecasts: Open-Meteo, using Copernicus Atmosphere Monitoring Service (CAMS) data, CC BY 4.0. Station readings: World Air Quality Index project. Coastlines: Natural Earth.
API conversion uses approximate PM2.5 breakpoints (15, 35, 150, 250 µg/m³ for API 50, 100, 200, 300) pending confirmation against DOE guidance. Indicative only; not a health service.
